Как это работает

Одна сеть за раз

Профили ниже сохраняют физический адаптер Mac. Сеть меняется только после подтверждения.

Без подмены результатов

При обрыве маршрута проверки встают на паузу. После смены источника начинается новый сеанс измерений.

LTE-сегмент роутера должен использовать мобильный WAN. Домашняя сеть не подхватывает проверки автоматически.
